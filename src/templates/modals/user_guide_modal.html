Khởi Động Nhanh (Quickstart Guide)

Nắm bắt kiến trúc hệ thống, hai chế độ triển khai và quy trình thao tác cơ bản trong 2 phút.

Hệ thống vận hành theo kiến trúc Hai Tầng (Dual-Mode Architecture):
• Bản Web / Cloud (Render.com): Tập trung 100% vào Tin học Văn phòng (PDF, Word, Excel, Slide, Sơ đồ, In ấn), tối ưu RAM siêu nhẹ dưới 512MB.
• Bản Máy Trạm (Local Machine): Toàn bộ tính năng Văn phòng + 14 Phân hệ BA Doanh nghiệp (BABOK Stories, Use Cases, RTM, DBML, Satsuma Lineage, SQL Suite, Cẩm Nang Luật Lao Động & Regulatory Watcher).
3 Bước Thao Tác Cơ Bản Quy trình
  1. Chọn Tab nghiệp vụ: Thanh menu trên cùng (Document Hub, Spreadsheet Studio, Diagram Studio, v.v.).
  2. Tải tệp hoặc chọn mẫu: Kéo thả file (.pdf, .docx, .xlsx, .json) hoặc chọn mẫu có sẵn.
  3. Thực thi & Tải về: Bấm nút xử lý (Convert, Audit, Render). Tệp thành phẩm tự động ghi vào Lịch Sử.
Cấu Trúc Phím Tắt & Truy Cập Nhanh Phím Tắt
  • In Ấn: Mở Trạm in ngầm silent print ngay từ thanh tiêu đề.
  • Lịch Sử: Xem và tải lại các file đã xử lý gần đây.
  • Giao Diện: Chuyển đổi nhanh Dark / Light Mode.
  • Esc: Đóng mọi cửa sổ sổ phụ hoặc modal đang mở.

Mẹo Tối Ưu Hiệu Năng & Khắc Phục Khựng Chuột

Nguyên nhân kỹ thuật và giải pháp triệt để khi máy tính bị khựng/lag chuột sau khi chạy tác vụ.

Tại sao máy tính bị khựng chuột và tắt Antigravity vẫn bị?
Máy tính của bạn trang bị chip AMD Ryzen 7 8845HS và card đồ họa AMD Radeon 780M (RDNA3). Khi các ứng dụng đồ họa (Electron, Chrome, WebView2) vừa chạy xong tác vụ nặng và đóng lại, driver AMD Radeon Software (AMDRSServ.exe) gặp hiện tượng lệch chu kỳ hiển thị Multi-Plane Overlay (MPO) với Desktop Window Manager (DWM) của Windows 11. Con trỏ chuột bị drop frame do DWM bị nghẽn đồng bộ với driver màn hình.
1. Phím Tắt Khởi Động Lại Driver Màn Hình (0.5 giây) Khắc Phục Tức Thì

Khi thấy chuột vừa bị khựng, bấm ngay tổ hợp phím:

Win + Ctrl + Shift + B

Màn hình sẽ chớp đen trong 0.5 giây rồi kêu tiếng bíp nhỏ. Lệnh này buộc Windows giải phóng toàn bộ MPO planes bị kẹt và khởi động lại pipeline DWM. Chuột sẽ mượt lại 100% ngay lập tức mà không làm mất ứng dụng nào đang mở.

2. Tắt AMD FreeSync Cho Desktop AMD Adrenalin

Mở ứng dụng AMD Software: Adrenalin Edition trên máy tính:

  • Vào mục Gaming ➔ Display ➔ Tắt Radeon FreeSync hoặc chọn chế độ chỉ bật khi chơi game toàn màn hình (Fullscreen only).
  • Vào tab Graphics ➔ Tắt Radeon Anti-Lag và Radeon Boost (các tính năng này hook vào desktop swapchain gây giật chuột).
3. Thêm Ngoại Trừ Windows Defender (Exclusion) Hạ DPC Latency

Khi chạy test suite hoặc xử lý tài liệu, hàng trăm file tạm được ghi/xóa, Windows Defender (MsMpEng.exe) quét thời gian thực đẩy độ trễ ngắt DPC lên cao khiến chuột bị delay tín hiệu USB:

  • Mở Windows Security ➔ Virus & threat protection settings ➔ Exclusions.
  • Thêm thư mục dự án: d:\New folder (4)\antigravity-doc-handler-main
  • Thêm thư mục IDE: C:\Users\HP\.antigravity-ide
4. Chế Độ Nguồn Best Performance CPU Core Parking

Chip AMD 8845HS có cơ chế tiết kiệm điện rất nhạy (Energy Performance Preference). Sau tác vụ nặng, CPU lập tức hạ xung về 1.1 GHz và đỗ lõi (Core Parking). Khi lia chuột, việc đánh thức lõi từ trạng thái ngủ sâu (C6) gây ra độ trễ vi mô:

  • Vào Windows Settings ➔ System ➔ Power & battery.
  • Chọn Power mode: Best performance khi cắm sạc.
5. Chạy Lệnh Bảo Trì & Kiểm Tra MPO Định Kỳ Lệnh CLI Tự Động

Quét và dọn sạch các tiến trình ngầm mồ côi (headless LibreOffice/Edge), thu hồi RAM và kiểm tra xem MPO có bị bật lại không:

python ai_tools_cli.py system-maintenance
